# Logo sources

These locally served assets identify the companies, programs, projects, and profiles named in the portfolio. Their artwork, colors, and proportions are retained.

- `linkedin.png`: LinkedIn's official [in-logo package](https://content.linkedin.com/content/dam/me/business/en-us/amp/xbu/linkedin-revised-brand-guidelines/logos/in-logo.zip), linked from its [brand downloads](https://brand.linkedin.com/downloads). Original file: `in-logo/LI-In-Bug.png`.
- `amazon.png`: the [official Amazon press-center icon](https://press.aboutamazon.com/favicon-32x32.png).
- `gsoc.svg`: the [official Google Summer of Code sun](https://developers.google.com/static/open-source/gsoc/images/sun.svg), used by the program's [marketing resources](https://developers.google.com/open-source/gsoc/resources/marketing).
- `oppia.svg`: Oppia's [official 48-pixel logo](https://raw.githubusercontent.com/oppia/oppia/develop/assets/images/logo/48x48_logo_mint.svg).
- `localjot.png`: the owner's original LocalJot macOS app icon, from `Resources/AppIcon.iconset/icon_32x32@2x.png`.
- `go-careers.jpg`: the [Go Careers organization's GitHub avatar](https://avatars.githubusercontent.com/u/48249709?v=4&s=128).
- `github.png`: the [official GitHub mark](https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png).
- `medium.ico`: the [official Medium site icon](https://medium.com/favicon.ico).
- `jiit.jpg`: the [official JIIT logo](https://www.jiit.ac.in/img/logo-new-mobile.jpg), used in the university website’s mobile header.

Brand marks belong to their respective owners. Text labels provide the accessible names; adjacent logos are decorative to avoid repeating those names in screen readers.
